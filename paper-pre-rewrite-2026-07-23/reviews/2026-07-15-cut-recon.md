## 0. Two facts that set the whole target

1. **Measured length = 11 pages**, and it is the same in `review` and non-`review` mode (I rebuilt with
   `\documentclass[sigconf]{acmart}` in the copy — line numbers don't change acmart pagination here).
2. **⚠️ The local build over-counts.** `main.tex` disables microtype expansion and falls back to
   Computer-Modern/Latin-Modern because the machine lacks Libertine/newtxmath. Those fallbacks set *wider*
   than the ACM Libertine 9.5pt that Overleaf (full TeX Live) will use. **Expect the real camera-ready to be
   ~0.5–0.75 page shorter than what I measured.** Every number below carries roughly ±0.5 pg of build
   uncertainty — confirm against an Overleaf compile before committing to any plan.

**Also confirm the actual limit.** The task targets **8 content pages + refs**. Recent KDD research-track CFPs
have variously used *9 pages incl. refs* and *8+refs* — the plan below is computed for **8 content pages** and
I also give the **9-page** landing so the author can pick once the CFP is checked. **If KDD allows an unlimited
appendix / supplementary** (it usually does), the whole problem collapses from "delete" to "relocate" — see §5.

## 4. Table-consolidation options (the ~6 §4 tables)

**Merge A — Tables 3 (ablation) + 5 (baselines) → one "cross-arm comparison at matched budget."**
Both are `arm × {ΔF_causal, ΔF_spatial}` at matched budget; Table 5 already carries the FAMAIL trim+lift row.
Add FAMAIL **trim-only** as a row, and the perturbation/oversampling arms below it. The two **SF ablation rows**
(SF ΔF_causal, SF migrant DP gap) don't share the ΔF_spatial/inflation columns — put them in a 2-row sub-panel
titled "San Francisco (ablation)" beneath, or fold into the SF section as inline numbers. Recovers ~0.16 pg + a
caption; also *strengthens* the story (FAMAIL, its ablation, and every non-fairness arm in one glance).

**Merge B — Tables 1 (SZ external) + 2 (channels) → one "Shenzhen data-level fairness."**
Both are the SZ migrant axis; the mean(Y|disadv) +0.0529 row is *shared* (it's the "Total" of the channel table
and a row of the external table). Stack the DP/DI/Theil/levels block above a "channel decomposition of Δmean(Y)"

**Do not merge** Table 4 (four-source L1 — different columns: Fid-A/Fid-B) or Table 6 (feature-set grid — its
own row structure). Merges A and B together recover ~**0.28 pg with zero information loss** — the cheapest page
in the paper.

footnotes, tables merged not deleted, restatement trimmed). **This is the recommended plan** if the CFP forbids
an appendix. If it's still ~0.2 over after Overleaf, add C8's full single-column conversion (+0.08).

### Plan B — Aggressive (structure-changing; buys slack for rebuttal additions)
Use this if you also need room to *add* a fairness baseline (reviewer-sim obj. 2) or the SF tier-2 recount
(obj. 3) — i.e. you want to land at ~7.5 pages so new results fit.

| Action | Recovered |

weight-choice justification) **unless the material lands in an appendix** — so Plan B is only advisable when the
appendix is allowed (§5). Without an appendix, Plan B's C9/C10 trade page count for reject-surface — not worth it.
