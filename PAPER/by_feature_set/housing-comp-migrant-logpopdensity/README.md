# housing-comp-migrant-logpopdensity — density-augmented F_causal (SENSITIVITY)

**Role: robustness / sensitivity appendix.** F_causal here uses **four** axes
{AvgHousingPricePerSqM, CompPerCapita, MigrantRatio, **LogPopDensity**}. This set adds a population-**density** demand
control to the equity axes. It is reported to show the two-pillar argument **survives a richer lens that conditions on
demand density** — it is **not** the paper's headline metric (see `../housing-comp-migrant/` for the PRIMARY equity
set, and `../../feature_selection/` for why).

> **Why this is the sensitivity slot, not the headline.** The before-edit F_causal drop vs the base SES/income set
> (0.807 → 0.725) is driven **~90% by LogPopDensity**, which is a demand-geography variable, **not a protected/
> demographic attribute**; MigrantRatio's incremental contribution here is ~0. A reviewer can fairly argue the editor
> is partly chasing low-density (sparse-demand) cells rather than underserved demographic groups. We keep this set to
> demonstrate robustness, but rest the *demographic* fairness claim on the PRIMARY set. Full rationale in
> `../../feature_selection/README.md`.

## Headline numbers (cleaned data, 4-feature F_causal; all values are seed MEANS)

- **Editor (causal-emphasis α = 0.2/0.7/0.1, k = 10000):** F_causal 0.7253 → **0.7409** (Δ **+0.0156**);
  F_spatial 0.1034 → 0.1024.
- **Pillar 1 (L1 — data quality):** edited is the **fairest faithful** source — F_causal: edited **0.7409** > raw
  0.7253 ≈ **bc 0.7252** (bc and raw are statistically tied, Δ ≈ 7e-5); gan 0.7369 is distributionally disqualified
  (Fidelity-B 0.173 vs edited 0.154 — but gan collapses, see fidelity panel). Fidelity-A: all four within 0.006
  (edited 0.843 ≈ raw 0.849), so editing is identity-faithful.
  - *Deterministic-gap caveat:* raw and edited F_causal have **std = 0** across BC seeds — they are static data-level
    rescores, so the edited−raw gap is a **point comparison with no sampling CI** and no paired test applies. It is
    also the editor's own optimization target (α_causal = 0.7), so the gap is expected *by construction*; its value is
    that it is achieved while Fidelity-A is unchanged.
- **L2 (vanilla transfer):** edited−raw ΔF_causal **−0.0010** (within the ±0.003 cross-seed band; n = 5, n.s.) —
  vanilla driver-conditioned BC averages the edit away. *(At n = 5 a two-sided Wilcoxon cannot reach p < 0.05, floor
  0.0625; reported as effect-vs-noise, not a powered zero test.)*
- **Pillar 2 (weighted BC):** upweighting **recovers** it — edited ΔF_causal **+0.0190 / +0.0255 / +0.0274** at
  w = 10/20/30 (t-CIs [+0.018,+0.020] / [+0.023,+0.028] / [+0.024,+0.031], all exclude 0; monotone dose-response;
  6/6 seeds same sign).
- **Edit ≫ select > random:** edited_w30 **+0.0274** vs most_fair_w30 **+0.0022** vs random_w30 **+0.0013** (n.s.).
  Editing dominates; selection captures only ~1/12 of the gain and is **metric-dependent** (see caveat); the random
  placebo is **null on F_causal**.
- **Model-level (variance suite, b0 vs FAMAIL):** ΔF_causal **+0.0006** (within noise; null).

## Statistical caveats (see top-level README for the full conventions)

- **`p = 0.03125` is the n = 6 Wilcoxon floor** (= all 6 seeds same sign), not a magnitude. Read effects from the
  means + t-CIs above. No weighted-BC test survives Bonferroni at n = 6; the evidence is CI-separation + dose-response
  + sign-consistency + null placebo.
- **most_fair (SELECT) is weak and metric-dependent, not a robust tier.** Here most_fair_w30 = +0.0022 with
  `p = 0.03125` — but that is exactly the all-6-same-sign floor, and under the 3-feature metric the same arm is
  **+0.0012, n.s. (p = 0.5625, mixed sign)**. So SELECT does **not** replicate across metrics; only EDIT (+0.027,
  robust in both) and RANDOM (null in both) are robust. Treat the ordering as **EDIT ≫ select > random** (a gradient),
  not "select is a significant tier."
- **Random placebo is null *on F_causal* specifically.** On Fidelity-B the random arm *does* show a small significant
  shift (random_w30 ≈ +0.0028, p = 0.03125) — a generic oversampling/distribution-shift effect. The edit-specificity
  claim rests on F_causal, where the random arm is genuinely null (+0.0013, p = 0.31).
