# housing-gdp-comp — original 3-feature F_causal (SENSITIVITY / baseline)

**Role: sensitivity / historical baseline.** F_causal here uses the original **three** axes
{AvgHousingPricePerSqM, GDPperCapita, CompPerCapita} — neighborhood wealth, area GDP, and compensation (SES/income).
This is the set the project used before the migrant/density exploration. It is reported to show the two-pillar
argument **predates** the PRIMARY equity-set choice and does not depend on it. The paper's headline numbers come from
`../housing-comp-migrant/` (the PRIMARY equity set).

## Headline numbers (cleaned data, 3-feature F_causal; all values are seed MEANS)

- **Editor (causal-emphasis α = 0.2/0.7/0.1, k = 10000):** F_causal 0.8069 → **0.8193** (Δ **+0.0124**);
  F_spatial 0.1034 → 0.1025.
- **Pillar 1 (L1 — data quality):** edited is the **fairest faithful** source — F_causal: edited **0.8193** > raw
  0.8069 ≈ **bc 0.8064** (bc and raw effectively tied); gan 0.8153 is distributionally disqualified (it collapses,
  see fidelity panel). Fidelity-A: all four within ~0.005 (edited 0.844 ≈ raw 0.848), so editing is identity-faithful.
  - *Deterministic-gap caveat:* raw and edited F_causal have std = 0 across BC seeds (static data-level rescores) —
    the edited−raw gap is a point comparison with no sampling CI, and is the editor's own optimization target
    (α_causal = 0.7), so the gap is expected by construction; its value is being achieved while Fidelity-A is unchanged.
- **L2 (vanilla transfer):** edited−raw ΔF_causal **−0.0009** (within the ±0.003 cross-seed band; n = 5, n.s.) —
  vanilla BC averages the edit away. *(n = 5 two-sided Wilcoxon cannot reach p < 0.05, floor 0.0625.)*
- **Pillar 2 (weighted BC):** upweighting **recovers** it — edited ΔF_causal **+0.0175 / +0.0222 / +0.0260** at
  w = 10/20/30 (t-CIs [+0.015,+0.020] / [+0.019,+0.025] / [+0.024,+0.028], all exclude 0; monotone; 6/6 same sign).
- **Edit ≫ select > random:** edited_w30 **+0.0260** vs most_fair_w30 **+0.0012 (n.s., p = 0.5625, mixed sign)** vs
  random_w30 **−0.0004 (n.s.)**. Under this metric SELECT is **null** — which (together with the density set, where it
  is a tiny all-same-sign +0.0022) is exactly why we treat selection as a weak, **metric-dependent** effect, not a
  robust tier: only EDIT and RANDOM are stable across metrics.
- **Model-level (variance suite, b0 vs FAMAIL):** ΔF_causal **−0.0004** (within noise; null).

## Statistical caveats

- `p = 0.03125` (where it appears, e.g. the edited_wN arms) is the **n = 6 Wilcoxon floor** = all-6-seeds-same-sign,
  not a magnitude; read effects from the means + t-CIs. No weighted-BC test survives Bonferroni at n = 6.
- F_causal is **associational** (partial R² of a cross-sectional OLS on **10 district-level** demographic profiles),
  not causal; ecological-fallacy caveat applies. See `../../feature_selection/README.md`.
